# Oliviermichaelis Tap

## How do I install these formulae?

`brew install oliviermichaelis/tap/<formula>`

Or `brew tap oliviermichaelis/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "oliviermichaelis/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
